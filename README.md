# Task Manager Backend

Backend for Task Manager application built using Node.js, Express, and MongoDB.

## Features
- JWT Authentication
- Role Based Access Control (RBAC)
- Task Management APIs
- Secure Middleware

## Tech Stack
- Node.js
- Express
- MongoDB

## Setup
1. Clone the repository
2. Create `.env` using `.env.example`
3. Run:
   npm install
   npm run dev
